Twitch Hybrid DVR

A browser extension that adds seamless rewind to Twitch live streams using the current VOD when available and a temporary local buffer as fallback.

What it does

Hybrid rewind

Uses the current Twitch VOD for deep rewind and a rolling local DVR near LIVE.

Seamless playback

Rewind and return to LIVE without navigating away from the channel page.

Temporary local data

The local buffer lives in the current tab and is discarded when the stream or tab is closed or refreshed.
